ALMERI FELDBUCH – KURZANLEITUNG v1.3
=====================================

NEU IN VERSION 1.3
- Almeri Branding und Logo.
- Ganze Projekte löschen.
- Einzelne Schleifen innerhalb eines Projekts löschen.
- Die Liste „Letzte Messungen“ zeigt nur die aktive Schleife.
- Vorhandene Daten aus älteren Versionen werden übernommen.

WICHTIG VOR JEDEM UPDATE
1. In der App unter Feldbuch eine JSON-Sicherung exportieren.
2. Die bestehende Home-Bildschirm-App nicht löschen.
3. Nur die Programmdateien im GitHub-Repository ersetzen.

UPDATE ÜBER GITHUB PAGES
1. AlmeriFeldbuch_iPhone_v1_3.zip am PC entpacken.
2. Das Repository unter GitHub öffnen.
3. Code -> Add file -> Upload files.
4. Den kompletten INHALT des Unterordners „AlmeriFeldbuch“
   ins Hauptverzeichnis des Repositorys hochladen und vorhandene Dateien ersetzen.
5. Commit changes klicken.
6. Nach dem Pages-Build im iPhone-Safari öffnen:
      https://almerivermessung.github.io/Nivellement/?v=1.3
7. Falls noch die alte Version angezeigt wird:
   - Seite neu laden
   - Web-App vollständig schließen und neu öffnen
   - notfalls erneut zum Home-Bildschirm hinzufügen

LÖSCHEN VON DATEN
- Aktive Schleife löschen:
  Im Reiter Projekt auf „Aktive Schleife löschen“ tippen.
  Wenn es die letzte Schleife des Projekts ist, wird automatisch eine neue leere Schleife angelegt.

- Aktives Projekt löschen:
  Im Reiter Projekt auf „Aktives Projekt löschen“ tippen.
  Wenn es das letzte Projekt ist, wird automatisch ein neues leeres Projekt angelegt.

HINWEIS ZU „LETZTE MESSUNGEN“
Diese Liste zeigt nur Messungen aus der aktuell aktiven Schleife.

BACKUP
Im Reiter Feldbuch über „Sicherung JSON“ exportieren.
